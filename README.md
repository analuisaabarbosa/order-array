# Order Arrays 🎲
Este projeto permite ordenar e pesquisar arrays de números e letras de forma interativa. Desenvolvido com HTML, CSS e JavaScript, a aplicação exibe dois arrays: um de números de 0 a 9 e outro com as letras do alfabeto (a-z). 
O usuário pode ordenar ambos os arrays de forma crescente ou decrescente e pesquisar por números ou letras. Quando uma pesquisa é realizada, o sistema indica se o item está presente e mostra sua posição no array.

# 🚀 Funcionalidades
* Ordenação Crescente e Decrescente: Ordene os arrays de números e letras em ordem crescente ou decrescente.
* Pesquisa Dinâmica: Pesquise por números ou letras e o sistema irá informar se o item está presente e sua posição no array.
